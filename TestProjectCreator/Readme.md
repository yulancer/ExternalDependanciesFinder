
# TestProjectCreator

Это консольное приложение на C# для автоматизации следующих шагов:

1. **Получение параметров из командной строки (именованные параметры)**  
   Приложение принимает следующие именованные параметры:
    - **--PackageName** — имя NuGet-пакета (и библиотеки).
    - **--Version** — версия NuGet-пакета.
    - **--DotnetVersion** — целевая версия .NET (target framework) для тестового проекта.

2. **Подготовка директории решения**  
   Если директория решения существует, она удаляется. Затем создаётся новая директория.

3. **Создание решения (TestSolution.sln)**  
   Выполняется команда:

   ```bash
   dotnet new sln -n TestSolution
   ```

4. **Создание тестового проекта (xUnit) с указанным target framework**  
   Выполняется команда:

   ```bash
   dotnet new xunit -n TestProject -f <DotnetVersion>
   ```

5. **Добавление проекта в решение**  
   Выполняется команда:

   ```bash
   dotnet sln add TestProject/TestProject.csproj
   ```

6. **Добавление NuGet-пакета в проект**  
   Выполняется команда, которая добавляет пакет с именем PackageName и версией Version:

   ```bash
   dotnet add TestProject/TestProject.csproj package <PackageName> --version <Version>
   ```

7. **Восстановление и сборка проекта**  
   Выполняются команды:

   ```bash
   dotnet restore TestProject/TestProject.csproj
   dotnet build TestProject/TestProject.csproj
   ```

8. **Определение директории с артефактами сборки**  
   Приложение определяет папку, где находятся файлы сборки (DLL, PDB).

9. **Загрузка символов (PDB) для DLL**  
   Для файла `<PackageName>.dll` приложение пытается загрузить символы с сервера Microsoft, а при неудаче – с сервера nuget.org.

10. **Подготовка тестового файла**  
    Из файла-шаблона `NugetDllAnalyzerTests.cs.txt` создаётся тестовый файл, в котором имя библиотеки заменяется на `<PackageName>.dll`. Затем проверяется наличие соответствующих файлов (DLL и PDB).

11. **Запуск тестов с измерением покрытия кода**  
    Тесты выполняются с опцией измерения покрытия, а результаты сохраняются в папку `TestResults`:

    ```bash
    dotnet test --blame --collect:"Code Coverage" --results-directory "TestResults"
    ```

12. **Перемещение файлов результатов**  
    Файлы результатов из подпапок перемещаются в корневой каталог `TestResults`, а подпапки удаляются.

13. **Конвертация результатов покрытия в XML**  
    Все файлы покрытия (*.coverage) объединяются в один XML-файл:

    ```bash
    dotnet coverage merge *.coverage -o outfile.xml -f xml
    ```

14. **Вывод результатов покрытия**  
    Из файла `outfile.xml` выводятся значения атрибутов `block_coverage` и `line_coverage` для модуля `<PackageName>.dll`.

## Предварительные условия

- **.NET SDK**  
  Убедитесь, что установлен .NET SDK, подходящий для указанного target framework.  
  Скачать можно по ссылке: [скачать .NET SDK](https://dotnet.microsoft.com/en-us/download).

- **Глобальный инструмент dotnet-symbol**  
  Для загрузки символов выполните:

  ```bash
  dotnet tool install --global dotnet-symbol
  ```

  Убедитесь, что путь к инструментам (обычно `C:\Users\<UserName>\.dotnet\tools`) добавлен в PATH.

- **Интернет-соединение**  
  Необходимо для загрузки шаблонов, NuGet-пакетов и символов.

- **Файл тестов**  
  Файл `NugetDllAnalyzerTests.cs.txt` должен находиться в исполняемой папке программы.

## Параметры командной строки

Запускайте приложение, передавая следующие именованные параметры:

- **--PackageName**: Имя NuGet-пакета (например, `Newtonsoft.Json`).
- **--Version**: Версия пакета (например, `13.0.1`).
- **--DotnetVersion**: Целевая версия .NET (например, `net6.0`).

Пример запуска:

```bash
dotnet run --PackageName=Newtonsoft.Json --Version=13.0.1 --DotnetVersion=net6.0
```

## Как использовать

1. **Клонируйте или скачайте репозиторий с проектом.**

2. **Соберите проект**  
   Откройте терминал в каталоге проекта и выполните:

   ```bash
   dotnet build
   ```

3. **Запустите приложение с именованными параметрами**  
   Например:

   ```bash
   dotnet run --PackageName=Newtonsoft.Json --Version=13.0.1 --DotnetVersion=net6.0
   ```

   Приложение выполнит следующие действия:
    - Создаст решение и тестовый проект.
    - Добавит указанный NuGet-пакет.
    - Восстановит зависимости и соберёт проект.
    - Скачает символы для сборки.
    - Подготовит тестовый файл.
    - Запустит тесты с измерением покрытия кода.

---

## Отладка и устранение неполадок

- Если не удаётся загрузить глобальный инструмент `dotnet-symbol`, проверьте, установлен ли он и добавлен ли путь к нему в PATH.
- При повторном запуске приложение удаляет папку `TestSolution`, чтобы избежать конфликтов.
- Если отсутствует тестовый файл (`NugetDllAnalyzerTests.cs.txt`) или не удаётся выполнить замену, приложение завершится с ошибкой.
- Если отсутствует DLL или PDB файл, выполнение прервётся с соответствующим сообщением.
- Для диагностики ошибок проверьте вывод консоли.
